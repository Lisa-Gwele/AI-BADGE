## Context Overflow

The context window is how much text can AI work with at one time. I gave Claude my daughter’s name at the beginning of the chat and gave it a lot of unrelated material and later asked it to remember the name and it did. So unfortunately, the test did not show overflow despite trying again with more material.

## Hallucination
